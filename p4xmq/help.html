このアプリはQuickスキャンによるXAFS測定のために、モノクロメータ・測定対象元素と吸収端、 およびスキャンパラメータを設定するためのツールです。 設定したパラメータはファイルとして保存・読込することができます。



Monochrometer


　分光結晶の結晶面を選択します。


  • Si(111): d = 3.13551 Å
  • Si(311): d = 1.63747 Å
  • Si(220): d = 1.92010 Å
  • Other...: 任意の格子定数[Å]を入力できます

　選択された結晶面に対応する格子面間隔が右側に表示されます。



Elements


　測定対象の元素と吸収端を選択します。


  • Element: 測定対象の元素記号

  • Edge: 吸収端［K, L1, L2, L3, M］

　選択した元素・吸収端に対応する吸収端エネルギー(eV)とブラッグ角が右側に表示されます。


※一般的なSi2結晶分光器では測定できないエネルギー領域の吸収端はグレーアウトされ選択できません。



Parameters


　Quickスキャンのパラメータを設定します。


  • Begin [eV]: スキャン開始エネルギー

    • ΔE0 [eV]: 吸収端からの相対エネルギー（Begin = E0 + ΔE0）

    ※BeginとΔE0は連動しており、一方を変更するともう一方が自動更新されます。


  • End [eV]: スキャン終了エネルギー

    • K: 波数 [Å-1]（End = E0 + K² / 0.2625）

    ※EndとKは連動しており、一方を変更するともう一方が自動更新されます。


  • Step [eV]: ステップ幅

    • 右側に「Total points（総測定点数）」が表示されます。


  • Exposure [sec.]: スキャン全体の露光時間

    • 右側にモノクロメータの主軸回転速度 [°/sec.] が表示されます。


※実際のQuickスキャンでは、等速回転するモノクロメータに対して等時間間隔でデータ収集をおこなうため、 厳密には「等エネルギー間隔」とはなりません。Step値は「分光器がE0近傍を通過する際の エネルギー間隔がStep[eV]となるような等時間間隔でデータ収集が行われる」ことを意味します。



File


　パラメータの保存・読込を行います。


  • Save as: 現在のパラメータをファイルとして保存します

    • Agenda (SAGA-LS)：SAGA-LS形式のAgendaファイル（.agenda）として保存

  • Load from: 設定ファイルを読み込み、現在のパラメータとして復元します

    • Agenda (SAGA-LS)：SAGA-LS形式のAgendaファイルを読み込み


※ファイルをカード上にドラッグ＆ドロップすることでも読み込みが可能です。
