このアプリはXAS（X線吸収分光）のQuickスキャン測定におけるモノクロメータおよびスキャンパラメータを計算・設定するためのツールです。 設定したパラメータはSAGA-LS形式のAgendaファイルとして保存・読込することができます。



Monochrometer


　分光結晶の結晶面を選択します。


  • Si(111): d = 3.13551 Å
  • Si(311): d = 1.63747 Å
  • Si(220): d = 1.92010 Å
  • Other...: 任意の格子定数(d)を入力できます

　選択された結晶面に対応する格子面間隔(d)が右側に表示されます。 「Other...」を選択した場合は、格子面間隔を直接入力することができます。



Elements


　測定対象の元素と吸収端を選択します。


  • Element: 測定対象の元素記号を選択します

  • Edge: 吸収端（K, L1, L2, L3）を選択します

　選択した元素・吸収端に対応する吸収端エネルギー(eV)とブラッグ角が右側に表示されます。


※値が0の吸収端はグレーアウトされ選択できません。



Parameters


　Quickスキャンのパラメータを設定します。


  • Begin [eV]: スキャン開始エネルギー

  • ΔE0 [eV]: 吸収端からの相対エネルギー（Begin = Edge + ΔE0）

    • ※BeginとΔE0は連動しており、一方を変更するともう一方が自動更新されます。


  • End [eV]: スキャン終了エネルギー

  • K: 波数ベクトル（End = E0 + K² / 0.2625）

    • ※EndとKは連動しており、一方を変更するともう一方が自動更新されます。


  • Step [eV]: エネルギーステップ幅

    • 　右側にスキャン範囲のTotal points（総測定点数）が表示されます。


  • Exposure [sec.]: スキャン全体の露光時間

    • 　右側にモノクロメータの回転速度（°/sec.）が表示されます。



File


　パラメータの保存・読込を行います。


  • Save as: 現在のパラメータをSAGA-LS形式のAgendaファイル（.agenda）として保存します

  • Load from: Agendaファイルを読み込み、パラメータを復元します

※Agendaファイルをカード上にドラッグ＆ドロップすることでも読み込みが可能です。


※対応するスキャンタイプは「Quick」のみです。
