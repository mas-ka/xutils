P4XMQ - 操作マニュアル ＆ 仕様リファレンス

　P4XMQ は、Quickスキャン方式によるXAFS測定において、分光結晶、測定対象元素と吸収端、およびスキャンパラメータを設計・設定するためのツールです。

　設定した測定パラメータは、SAGA-LS形式のAgendaファイル（.agenda）として保存および読み込みが可能です。

Monochrometer

　分光器で使用する分光結晶の結晶面を選択します。

  • Si(111): 面間隔 d = 3.13551 Å
  • Si(311): 面間隔 d = 1.63747 Å
  • Si(220): 面間隔 d = 1.92010 Å
  • Other...: 任意の格子面間隔 d [Å] を直接手入力できます。

※選択された結晶面に対応する面間隔 d が右側に表示されます。

Elements

　測定対象となる元素および吸収端を選択します。

  • Element: 測定対象元素を元素記号プルダウンから選択します。
  • Edge: 測定する吸収端（K, L1, L2, L3, M）を選択します。

　選択した元素・吸収端に対応する吸収端エネルギー E₀ [eV] および分光結晶でのブラッグ角 θ [°] が右側のパネルに自動計算されて表示されます。

💡 選択不可な吸収端:
　選択中の分光結晶で幾何学的に到達できない（ブラッグ角が物理的限界外となる）エネルギー領域の吸収端は、プルダウン内でグレーアウトされ選択が無効化されます。

Parameters

　Quickスキャンのエネルギー範囲および速度・露光パラメータを設定します。

  • Begin [eV] / ΔE₀ [eV]: スキャン開始エネルギー
    • ΔE₀ は吸収端エネルギー E₀ からの相対エネルギー（Begin = E₀ + ΔE₀）です。
    • Begin と ΔE₀ は相互に連動しており、一方を変更するともう一方が自動更新されます。
  • End [eV] / K [Å⁻¹]: スキャン終了エネルギー
    • K は光電子波数（End = E₀ + K² / 0.262467）です。
    • End と K は相互に連動しており、一方を変更するともう一方が自動更新されます。
  • Step [eV]: 吸収端近傍での代表エネルギー分解能・ステップ幅
    • 設定されたステップ幅に基づき、全スキャン範囲での推定総測定点数（Total points）が右側に表示されます。
  • Exposure [sec.]: 1スキャン全体の露光時間（所要秒数）
    • 設定された露光時間に基づき、モノクロメータ主軸（ゴニオメータ）の回転速度 [°/sec.] が右側に自動計算されます。
💡 QuickスキャンにおけるStepの仕様:
　実際のQuickスキャンでは、等速回転するモノクロメータに対して等時間間隔でデータ収集を行うため、エネルギー軸上では厳密な等間隔にはなりません。Step は「吸収端 E₀ 近傍を通過する際のエネルギー刻みが指定された Step [eV] となるようなサンプリング周波数・時間間隔」を意味しています。

File

　設定したスキャンパラメータの保存および読み込みを行います。

  • Save as: 現在の測定パラメータをファイルとして書き出します。
    • Agenda (SAGA-LS): SAGA-LS形式のAgendaファイル（.agenda）として保存します。
  • Load from: 既存の設定ファイルを読み込み、パラメータを復元します。
    • Agenda (SAGA-LS): SAGA-LS形式のAgendaファイルを読み込みます。

※アプリ画面（カード上）へ .agenda ファイルを直接ドラッグ＆ドロップすることでも瞬時に読み込みが可能です。
