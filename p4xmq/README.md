# P4XMQ - Parameters for XAS Measurement in Quick Scan

**P4XMQ** は、高速連続走査方式（Quick Scan / QXAFS）によるX線吸収微細構造（XAFS）測定において、連続駆動角速度（deg/sec）、測定時間、サンプリングレート、エンコーダパルス分解能を連動設計し、QXAFS測定制御用ファイルを出力するためのWebアプリケーションです。

インストールの必要がなく、Webブラウザ上で動作します。

---

## 1. 特長

1. **クイックスキャン（QXAFS）専用パラメータ設計**:
   - 開始エネルギー・終了エネルギー、所要測定時間（秒）、分光器角速度、サンプリング点数の相互連動計算。
   - 分光器の機械的限界（最高速度・加速度）やエンコーダ分解能に応じた最適化。
2. **多重散乱・Glitch回避領域の事前チェック**:
   - 走査範囲内のブラッグ角変動と角速度プロファイルをリアルタイムに可視化。
3. **PF新フォーマット出力**:
   - PF（Photon Factory）や SAGA-LS 等のQXAFS測定制御システムに直接投入可能な「PF新フォーマット」出力に対応。
4. **クライアント完結動作**:
   - ブラウザ上で高速・安全にパラメータ試算・ファイル生成が完了します。

---

## 2. 画面構成と基本操作

### 1. 分光器設定 (Monochrometer)
- 分光結晶（Si(111), Si(220), Si(311) 等）の選択、格子面間隔 $d$ 値 [Å]、エンコーダ分解能、中心角度等の基本定数を設定します。

### 2. スキャン範囲・速度設定 (Scan Parameters)
- 測定開始エネルギー [eV] および終了エネルギー [eV] を設定します。
- スキャン時間 [sec.] または分光器角速度 [deg/sec] を入力すると、他方のパラメータおよびサンプリング周波数・総測定点数が自動計算されます。

### 3. パラメータの出力 (File Export)
- ツールバーの **「PF新フォーマット出力」** または **「パラメータ保存」** をクリックして測定ファイルを保存します。
