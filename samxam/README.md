# SAMXAM - Sample & Element Data Browser for XAFS

**SAMXAM** は、XAFS（X線吸収微細構造）測定および蛍光X線分析において必要な全元素の吸収端エネルギー、蛍光X線（特性X線）エネルギー、Auger電子エネルギーの参照、および標準物質のXAFSスペクトル閲覧を支援するWebアプリケーションです。

インストールの必要がなく、Webブラウザ上で動作します。

---

## 1. 特長

1. **全元素のエネルギーデータ即時参照**:
   - 元素周期表または元素記号から、K端、L端（L1, L2, L3）、M端（M1〜M5）の吸収端エネルギー（eV）を即座に表示。
   - K系列（Kα1, Kα2, Kβ1, Kβ2等）、L系列（Lα1, Lα2, Lβ1〜Lβ4, Lγ1等）、M系列の蛍光X線エネルギーを網羅。
   - KLL, LMM などの主要なAuger電子エネルギーを参照可能。
2. **標準XAFSスペクトルのインタラクティブ閲覧**:
   - 金属単体箔や主要標準化合物のXAFSスペクトル（μt vs Energy）をPlotly.jsによりインタラクティブに表示。
   - ズーム、パン、エネルギー値のツールチップ表示に対応。
3. **多重散乱（多電子励起・Glitch）警告 ＆ 佐々木研究室文献リンク**:
   - 吸収端近傍において多重散乱や干渉が生じやすい元素に対し、佐々木研究室（東京工業大学）のX線異常散乱・多電子励起に関する学術論文・データベースへの直接リンクを提供。
4. **クライアント完結動作**:
   - すべての処理はブラウザのJavaScript内で完結し、外部サーバーとの通信は行われません。

---

## 2. 画面構成と基本操作

### 元素の選択とエネルギー参照
1. **元素の指定**: 周期表の元素ボタンをクリックするか、検索ボックスに元素記号（例: `Fe`, `Cu`, `Pt`）を入力します。
2. **エネルギー一覧の確認**:
   - 左側パネルに選択元素の基本物性（原子番号、原子量、密度、電子配置等）と吸収端エネルギー一覧が表示されます。
   - 蛍光X線およびAuger電子エネルギーのテーブルから、目的の輝線エネルギーを確認できます。

### 標準スペクトルの閲覧
1. **スペクトル選択**: 該当元素に標準スペクトルデータが登録されている場合、スペクトル選択ドロップダウンから対象物質を選択します。
2. **スペクトルの確認**: グラフ描画領域にXANES/EXAFSスペクトルがプロットされます。
