# SAMXAM - Sample Preparation Calculator for XAFS

**SAMXAM** は、XAFS（X線吸収微細構造）測定における試料作製条件（ペレットの必要重量やフォイルの最適膜厚など）を計算するためのWebアプリケーションです。

ターゲット元素および化学組成を設定することで、各種吸収量基準（$\mu t_H$, $\Delta\mu t$）を満たす最適な試料量を算出します。

インストールの必要がなく、Webブラウザ上で動作します。

---

## 1. 特長

1. **フォイル・ペレット両形態の試料作製計算**:
   - **Foil（金属箔・フィルム）**: 試料密度から最適膜厚 [$\mu\text{m}$] を算出。
   - **Pellet（粉末成形ペレット）**: 成形ダイス内径、希釈材およびその量を指定して必要試料粉末重量 [mg] を算出。
2. **化学組成（原子比・重量比）に基づく吸収量評価**:
   - 構成元素と比率（Atom比 / Mass重量%）を設定可能。
   - 文献データ等に基づく質量吸収係数から、全吸収量 $\mu t_H$（高エネルギー側）、$\mu t_L$（低エネルギー側）、エッジジャンプ量 $\Delta\mu t$ を計算。
3. **測定基準に応じた適正量の判定 ＆ 警告表示**:
   - 推奨基準（$\mu t_H = 2.5$, $\Delta\mu t = 1.0$、上限 $\mu t_H = 4.0$）および任意厚さ・重量での逆算値を一覧表示。
   - 調合不可や吸収過大・秤量困難な極小量に対するカラーハイライト警告表示。
4. **クライアント完結動作**:
   - すべての処理はブラウザのJavaScript内で完結し、外部サーバーとの通信は行われません。

---

## 2. 画面構成と基本操作

### 1. Sample（試料形態・幾何条件設定）
- 試料形態（Foil または Pellet）を選択します。
- Pellet の場合は成形ダイス直径 [mm]、希釈材の種類（BN等）および厚さ [mm] / 重量 [mg] を設定します。

### 2. Components（化学組成設定）
- 測定対象元素（Target）と吸収端（K, L1, L2, L3）を選択します。
- 試料の構成元素（Element）および比率（Atom比 または Mass%）を入力します。

### 3. Results（計算結果の確認）
- 各吸収量基準（$\mu t_H = 4.0, 2.5$、$\Delta\mu t = 1.0$、および任意入力値）に対応する必要厚さ [$\mu\text{m}$] または必要重量 [mg] を確認します。
