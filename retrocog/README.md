# RetroCog - 9809-format XAFS Data Viewer

**RetroCog** は、日本の放射光施設で広く利用されている XAFS 測定データ「9809形式」ファイルを閲覧・確認するためのビューアWebアプリケーションです。

複数ファイルの一括読み込み、スペクトルグラフの描画、ヘッダや測定ブロックの確認、および SAGA-LS 形式の Agenda ファイルや MDR XAFS DB 登録用メタデータ YAML・サムネイル画像のエクスポートが可能です。

インストールの必要がなく、Webブラウザ上で動作します。

---

## 1. 特長

1. **9809形式データのスペクトルグラフ描画**:
   - 複数データ列から分子（Numerator）・分母（Denominator）を選択し、吸光度（$\ln(\text{分子}/\text{分母})$）または比（分子/分母）をプロット。
   - X軸はエネルギー [keV] またはブラッグ角 [deg.] に切り替え可能。
   - スキャンブロック境界エネルギーの縦破線表示に対応。
2. **複数ファイル・フォルダの一括ドラッグ＆ドロップ読み込み**:
   - フォルダごとのドロップによる再帰的ファイル読み込みと、ナビゲーションボタンによるスムーズなファイル切り替え。
3. **MDR XAFS DB 連携 ＆ メタデータエクスポート**:
   - 9809ヘッダから施設名、ビームライン名、分光器設定、測定日時等を抽出し、MDR XAFS DB 登録用メタデータ YAML（`.yml`）を生成・保存。
   - MDR 登録用の正方形サムネイル画像（1280×1280 px, PNG）を生成・保存。
4. **SAGA-LS Agenda ファイルへのエクスポート**:
   - 測定データのブロック構成をもとに、SAGA-LS 形式の測定パラメータファイル（`.agenda`）を再生成・出力。
5. **クライアント完結動作**:
   - すべての処理はブラウザのJavaScript内で完結し、外部サーバーとの通信は行われません。

## 2. 画面構成と基本操作

### 1. Files（ファイル読み込み ＆ ナビゲーション）
- ツールバーのファイルボタンまたは画面上へのドラッグ＆ドロップで9809形式ファイルを読み込みます。
- ナビゲーションボタン（先頭、前へ、次へ、最後）で表示ファイルを切り替えます。

### 2. Chart（スペクトル描画 ＆ サムネイル保存）
- 分子・分母のデータ列番号、`apply Log`（吸光度表示）、`show blocks`（境界表示）を設定してスペクトルを確認します。
- ツールバー右上のカメラボタンから MDR 登録用サムネイル画像をダウンロードできます。

### 3. Data / Header / Block（詳細情報 ＆ エクスポート）
- **Data**: 各測定点の計測データテーブルを確認。
- **Header**: ヘッダ情報の確認と、MDR 用メタデータ YAML（`.yml`）のエクスポート。
- **Block**: スキャンブロック構成の確認と、Agenda ファイル（`.agenda`）のエクスポート。
