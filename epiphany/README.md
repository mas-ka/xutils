# Epiphany - Post-productive ROI Processor for Spectrogram Data

**Epiphany** は、蛍光XAFS測定によって得られた2次元スペクトログラムデータ（TIFF形式）を読み込み、事後的にROIを設定・微調整して蛍光収量スペクトル（μt）を再計算し、9809形式のデータファイルとして書き出すためのWebアプリケーションです。

インストールの必要がなく、Webブラウザ上で動作します。

---

## 1. 特長

1. **2次元スペクトログラム（TIFF）の可視化**:
   - 励起エネルギー（横軸）× 蛍光エネルギー（縦軸）における蛍光X線強度（CPS: count per second）を2次元カラーマップで描画。
   - エネルギースライダーによる注目励起エネルギー位置の切り替え。
2. **ヒストグラム連動のインタラクティブなROI設定**:
   - 選択された励起エネルギーにおける「蛍光エネルギー × 蛍光強度」の1次元スペクトル（ヒストグラム）を表示。
   - 縦型レンジスライダーによる積分ROI（下限・上限）の設定と、赤色塗りつぶし領域のリアルタイム連動。
   - マウスドラッグによる拡大ズーム操作（ヒートマップ側も自動同期）。
3. **規格化蛍光収量スペクトル（μt）の再計算**:
   - ROI内総カウント / I₀ による蛍光XAFSスペクトル（μt vs Energy）を再計算して下部グラフにプロット。
4. **9809形式ファイルのエクスポート ＆ ヘッダプレビュー**:
   - TIFFファイル内に埋め込まれた9809ヘッダ情報のダイアログ確認。
   - 新たに再計算されたμtスペクトルデータを9809形式ファイル（`_ppXXXX-YYYY.dat`）としてエクスポート。
5. **TIFFデータ構造仕様のドキュメント内蔵**:
   - 32-bit Float 逆数格納、Double64結合、ヘッダ行・データ行ピクセル配置などのバイナリ仕様リファレンスを内蔵。

## 2. 画面構成と基本操作

### 1. TIFFファイルの読み込み
- ツールバー右上の【<i class="mdi mdi-import"></i>】ボタンをクリックしてTIFFファイル（`.tif`, `.tiff`）を選択するか、画面カード上へ直接ドラッグ＆ドロップします。

### 2. ROIの調整
- 下部のエネルギースライダーでピークが明瞭な励起エネルギーを選択します。
- 右側のヒストグラムを見ながら、縦型レンジスライダーで目的の蛍光ピークを挟むようにROI（積分範囲）を調整します。

### 3. μtスペクトルの確認と保存
- 下部パネルの「Post-productive μt」グラフで再計算されたスペクトルの形状・S/Nを確認します。
- ツールバーの【<i class="mdi mdi-export"></i>】ボタンをクリックし、9809形式ファイルとしてダウンロードします。
