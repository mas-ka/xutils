# P4XMS - Parameters for XAS Measurement in Step Scan

**P4XMS** は、ステップスキャン方式（Step Scan）によるX線吸収微細構造（XAFS）測定において、多領域（マルチブロック）の測定エネルギー範囲、ステップ幅（ΔE / Δk）、および各点での積算時間を最適に設計し、測定制御用ファイルを出力するためのWebアプリケーションです。

インストールの必要がなく、Webブラウザ上で動作します。

---

## 1. 特長

1. **直感的なマルチブロック測定設計**:
   - 前吸収端領域（Pre-edge）、XANES領域、EXAFS領域など、測定領域ごとにエネルギーステップ幅（eV単位または波数 k [Å⁻¹] 単位）や積算時間（秒）を個別に設定可能。
   - ブロックの追加、削除、結合、分割（エネルギー・波数の指定値で2分割）に柔軟に対応。
2. **分光結晶・エンコーダパラメータ連動**:
   - Si(111), Si(311), Si(220) 等の主要分光結晶および面間隔 $d$ 値、エンコーダ分解能、分光器定数に連動してブラッグ角を自動計算。
3. **高精度な所要測定時間・測定点数のリアルタイム算出**:
   - 各ブロックの測定点数、積算時間、軸移動時間を加味した総所要時間をリアルタイムに試算。
4. **PF新フォーマット ＆ 独自形式の入出力**:
   - 放射光施設（PF, SAGA-LS 等）のステップスキャン制御システムに対応した「PF新フォーマット」出力に対応。
   - 設定パラメータのJSON保存・再読み込み、クリップボード連携が可能。

---

## 2. 画面構成と基本操作

### 1. 分光器設定 (Monochrometer)
- 分光結晶（Crystal）を選択し、格子面間隔 $d$ 値 [Å] や角度オフセット等のパラメータを設定します。

### 2. 測定ブロックの編集 (Measurement Blocks)
- **基準エネルギー ($E_0$)**: 測定対象元素の吸収端エネルギー [eV] を設定します。
- **ブロック操作**:
  - `mdi-plus-circle`（追加）: 新しいブロックを末尾に追加。
  - `mdi-minus-circle`（削除）: 選択ブロックを削除。
  - `mdi-set-merge`（結合）: 隣接ブロックを統合。
  - `mdi-arrow-split-vertical`（分割）: 指定エネルギーまたは波数位置でブロックを2分割。
- **ステップ・時間設定**:
  - 各ブロックの開始・終了エネルギー（$E$ または $k$）、ステップ幅（$\Delta E$ または $\Delta k$）、測定時間 [sec.] を入力します。

### 3. パラメータの出力 (File Export)
- ツールバーの **「PF新フォーマット出力」** または **「パラメータ保存」** をクリックして測定ファイルをダウンロードします。
