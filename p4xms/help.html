このアプリはStepスキャンによるXAFS測定のために、モノクロメータ・測定対象元素と吸収端、 および複数ブロックからなるスキャンパラメータを設定・計算するためのツールです。 設定したパラメータはファイルとして保存・読み込むことができます。



Monochrometer


　分光結晶の結晶面や動作速度を設定します。


  • Crystal Plane: 分光結晶の結晶面を選択します

    • Si(111): d = 3.13551 Å
    • Si(311): d = 1.63747 Å
    • Si(220): d = 1.92010 Å
    • Other...: 任意の格子面間隔[Å]を入力できます

    選択された結晶面に対応する格子面間隔が右側に表示されます。


  • Bragg Axis Speed [°/sec.]: モノクロメータ主軸（ブラッグ角回転）の移動速度

  • Overhead [sec.]: 測定点ごとの制御・通信オーバーヘッド時間

※主軸速度およびオーバーヘッド時間は、総測定時間の見積もり計算に使用されます。



Elements


　測定対象の元素と吸収端を選択します。


  • Element: 測定対象の元素記号

  • Edge: 吸収端［K, L1, L2, L3, M］

　選択した元素・吸収端に対応する吸収端エネルギー (eV) とブラッグ角が右側に表示されます。


※一般的なSi2結晶分光器では測定できないエネルギー領域の吸収端はグレーアウトされ選択できません。


※元素または吸収端を変更すると、その吸収端エネルギー（E0）に合わせた標準的なパラメータに自動で初期化・設定されます。



Parameters


　Stepスキャンのための複数ブロックからなる測定パラメータを設定します。


※ブロックとは：測定エネルギー範囲を分割した各区間のことです。ブロックごとに異なる分割数/ステップ幅や露光時間を設定できるため、「XANES領域は微小ステップで細かく測定し、ノイズが増えるEXAFS領域は露光時間を延ばしてSN比を稼ぐ」といった、領域に応じた最適な測定条件を柔軟に組み立てることができます。


  • BOUNDARY ENERGY: 各ブロックの境界エネルギー

    • 境界エネルギー[eV]および吸収端からの相対エネルギー ΔE0[eV] / 波数 k[Å⁻¹]が表示されます。


    • 左端のハンバーガーボタン からブロックの操作を行えます：
      • 追加: 先頭または末尾に新しいブロックを追加します。
      • 削除: 先頭または末尾のブロックを削除します。
      • 結合: 途中の境界を削除し、前後のブロックを1つに結合します。

      • ※設定可能なブロック数は最大12ブロックです（上限に達すると追加・分割ボタンが無効化されます）。


    • 左側のk / ΔE0欄（紺色の角丸枠）をクリックすると、ダイアログで相対エネルギー ΔE0[eV]または波数 k[Å⁻¹]を入力して設定できます。
    • 右側のエネルギー値欄をクリックすると、ダイアログで境界エネルギーの絶対値[eV]を直接入力して設定できます。


  • INTERPOLATION: ブロック内のデータ点補間方法

    • 数値欄をクリックするとダイアログが開き、補間方法と値を設定できます。

    • Step [eV]: 指定したエネルギー間隔（ステップ幅）で測定します。
    • Division [div.]: ブロック内を指定した分割数で等分割して測定します。
    • 左端のハンバーガーボタン から：
      • 分割: 対象ブロックの中間エネルギーに新しい境界を追加し、2つのブロックに分割します。

  • EXPOSURE: 測定点ごとの露光時間 [sec.]

    • 数値欄をクリックしてダイアログから入力すると、該当ブロックの露光時間のみが個別に変更されます（±0.1秒単位）。一方、欄内の / ボタンをクリックすると、そのブロック以降にあるすべてのブロックの露光時間が同じ値に連動して一括変更（±1.0秒単位）されます。


【下部集計欄】

  • 開始〜終了エネルギー / 総ブロック数: 全体のスキャン範囲[eV]とブロック数を表示します。
  • Total pts: スキャン全体の総測定点数を自動計算して表示します。
  • ~ min.: 露光時間合計・分光器移動時間・オーバーヘッド時間から算出された推定総測定時間を表示します。

※推定総測定時間は概算です。実際の測定時間とは多少前後するため、実機に合わせて「Overhead」値で微調整してください。



File


　パラメータの保存・読み込みを行います。


  • Save as: 現在のパラメータをファイルとして保存します

    • Agenda (SAGA-LS): SAGA-LS形式のアジェンダファイル（.agenda）として保存・ダウンロード

  • Load from: 設定ファイルを読み込み、現在のパラメータとして復元します

    • Agenda (SAGA-LS): SAGA-LS形式のアジェンダファイルを読み込み

※ファイルを画面上にドラッグ＆ドロップすることでも読み込みが可能です。
