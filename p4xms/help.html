P4XMS - 操作マニュアル ＆ 仕様リファレンス

　P4XMS は、Stepスキャン方式によるXAFS測定において、分光結晶、測定対象元素と吸収端、および複数ブロックからなる測定パラメータを設計・設定するためのツールです。

　設定した測定パラメータは、SAGA-LS形式のAgendaファイル（.agenda）として保存および読み込みが可能です。

Monochrometer

　分光器で使用する分光結晶の結晶面や駆動パラメータを設定します。

  • Crystal Plane: 分光結晶の結晶面を選択します。
    • Si(111): 面間隔 d = 3.13551 Å
    • Si(311): 面間隔 d = 1.63747 Å
    • Si(220): 面間隔 d = 1.92010 Å
    • Other...: 任意の格子面間隔 d [Å] を直接手入力できます。
  • Bragg Axis Speed [°/sec.]: モノクロメータ主軸（ブラッグ角回転）の移動速度を設定します。
  • Overhead [sec.]: 測定点ごとの制御・通信オーバーヘッド時間を設定します。

※主軸速度およびオーバーヘッド時間は、総測定時間の見積もり計算に使用されます。

Elements

　測定対象となる元素および吸収端を選択します。

  • Element: 測定対象元素を元素記号プルダウンから選択します。
  • Edge: 測定する吸収端（K, L1, L2, L3, M）を選択します。

　選択した元素・吸収端に対応する吸収端エネルギー E₀ [eV] および分光結晶でのブラッグ角 θ [°] が右側のパネルに自動計算されて表示されます。

💡 パラメータの自動初期化:
　元素または吸収端を変更すると、その吸収端エネルギー E₀ に合わせた標準的なスキャンブロック構造およびパラメータへと自動的に初期化・更新されます。

Parameters

　Stepスキャンのための複数ブロックからなる測定条件を設定します。

💡 ブロック分割測定のメリット:
　エネルギー領域を複数ブロックに分割することで、「急峻な構造変化を持つXANES領域は微小ステップで細かく測定し、ノイズが増加する広域EXAFS領域は露光時間を延ばしてSN比を稼ぐ」といった、目的に応じた最適なスキャンシーケンスを構築できます。
  • BOUNDARY ENERGY（境界エネルギー設定）:
    • 各ブロックの境界エネルギー [eV] および吸収端からの相対エネルギー ΔE₀ [eV] / 波数 k [Å⁻¹] を表示します。
    • ブロック操作メニュー（）:
      • （追加）: 先頭または末尾に新しいブロックを追加します（最大12ブロックまで）。
      • （削除）: 先頭または末尾のブロックを削除します。
      • （結合）: 境界を削除し、前後のブロックを1つに統合します。
    • 左側の k / ΔE₀ 枠をクリックすると、ダイアログから相対エネルギー ΔE₀ または波数 k を指定して境界を設定できます。
    • 右側のエネルギー値欄をクリックすると、ダイアログから絶対エネルギー値 [eV] を直接指定して境界を設定できます。
  • INTERPOLATION（ブロック内のデータ点補間）:
    • 数値欄をクリックするとダイアログが開き、補間モードと数値を設定できます。
      • Step [eV]: 指定したエネルギー刻み（ステップ幅）で等間隔測定します。
      • Division [div.]: ブロック内を指定した分割数で等分割して測定します。
    • ブロックメニュー（）の （分割）をクリックすると、対象ブロックの中間エネルギーに新しい境界が追加され、2ブロックに分割されます。
  • EXPOSURE（測定点ごとの露光時間）:
    • 数値欄をクリックしてダイアログ入力すると、該当ブロックの露光時間のみが個別に変更されます（±0.1秒単位）。
    • 欄内の （増加）/ （減少）ボタンをクリックすると、そのブロック以降にあるすべてのブロックの露光時間が連動して一括変更（±1.0秒単位）されます。

【下部集計ステータス】

  • 開始〜終了エネルギー / 総ブロック数: 全体のスキャンエネルギー範囲 [eV] とブロック数を表示します。
  • Total pts: スキャン全体の総測定点数を自動集計します。
  • ~ min.: 露光時間合計・主軸移動時間・オーバーヘッド時間から算出した推定総測定時間を表示します。

File

　設定した測定パラメータの保存および読み込みを行います。

  • Save as: 現在の測定パラメータをファイルとして書き出します。
    • Agenda (SAGA-LS): SAGA-LS形式のAgendaファイル（.agenda）として保存します。
  • Load from: 既存の設定ファイルを読み込み、パラメータを復元します。
    • Agenda (SAGA-LS): SAGA-LS形式のAgendaファイルを読み込みます。

※アプリ画面（カード上）へ .agenda ファイルを直接ドラッグ＆ドロップすることでも瞬時に読み込みが可能です。
