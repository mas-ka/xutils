Pedagogue - 操作マニュアル ＆ 仕様リファレンス

　Pedagogue（ペダゴーグ） は、物質・材料研究機構（NIMS）が運営する「MDR XAFS DB」および日本XAFS研究会（JXS）「XAFSメタデータ共通仕様（20230203リリース版）」に準拠したメタデータ（metadata.yml / metadata.json）の作成・閲覧・編集・保存を支援するWebエディタです。

　項目（Key）と設定値（Value）を安全に入力できる編集コンソールに加え、構文ハイライト付きリアルタイムYAMLプレビューを備えています。

💡 安全なデータ取り込みとマージ（統合）:
　外部のYAML/JSONファイルを読み込む（取り込む）際、現在編集中のデータと突き合わせて自動で マージ（統合） します。
　もし同じ項目に異なる値が設定されていた場合は 「衝突（コンフリクト）」 を自動検知し、どちらの値を優先するか項目ごとに選べるため、既存のデータを不用意に上書き消去してしまう心配がありません。

1. トップバー ＆ メニューバー

　画面最上部のナビゲーションバーから、ファイル操作、編集履歴、各種ガイドの表示、および必須項目の入力進捗の確認が行えます。

  • Pedagogue メニュー:
    • Pedagogue について: バージョン（ビルド日付）、JXS仕様準拠表記、Pedagogue 本体の MIT ライセンス全文、および使用しているオープンソースライブラリ（Vue, Vuetify, js-yaml 等）の許諾条文一覧をダイアログ表示します。
  • ファイル (File):
    • ファイルから取り込み (YAML/JSON)...: ローカルの .yml / .yaml / .json ファイルを読み込みます。
    • 保存 ＞ YAML形式 (metadata.yml): MDR XAFS DB 登録用標準フォーマットである metadata.yml としてダウンロード保存します。
    • 保存 ＞ JSON形式 (metadata.json): metadata.json 形式でダウンロード保存します。
    • 新規作成 (全クリア): エディタ内のデータを初期化（全消去）します。
  • 編集 (Edit):
    • 元に戻す (Undo / Ctrl+Z): 直前の編集操作を1段階取り消します（最大30件）。
    • やり直す (Redo / Ctrl+Y): 取り消した操作をやり直します。
    • YAMLをコピー: 現在のプレビュー内容をクリップボードに一括コピーします。
    • クリップボードから取り込み (貼付)...: クリップボード内のYAML/JSONテキストを読み込み、現在編集中のデータとマージします。
  • ヘルプ (Help):
    • ヘルプ ＆ 仕様リファレンス: 右サイドドロワーを展開して本マニュアルおよびスキーマ辞書を表示します。
    • MDR XAFS DB について: NIMS MDR リポジトリの仕様説明および関連公式リンク（MDR / JXS）を表示します。
  • ステータスバッジ（進捗・警告表示）:
    • 必須: ○ / 11: JXS仕様で必須と定められた11項目の入力完了状況。全項目を満たすと緑色のチェック表示に変化します。
    • 推奨: ○ / 12: データの検索性や再利用性を高めるための推奨12項目の入力状況。
    • ⚠️ 仕様外: ○件: スキーマ辞書に定義されていない未定義項目が存在する場合にのみ警告表示されます（タイポの早期発見）。
    • 設定済: ○件: 現在メタデータ内に値が設定されている全項目数。

2. メタデータ編集コンソール (左ペイン)

　画面左側のパネルで、編集したい項目（Key）を指定し、設定値（Value）を1項目ずつ安全に入力・更新します。

メタデータ編集フォーム (上部)

  • Key 入力フォーム（項目の選択）:

    　Key 入力欄から編集したい項目を選択します。ドロップダウン一覧から選択できるほか、文字を入力して検索することも可能です。

    💡 便利なインクリメンタル検索（サジェスト機能）:
    　「試料」「温度」「結晶」といった 日本語 や、「sample」「title」などの 英字Key名 を入力すると、該当する項目がリアルタイムに絞り込まれます。
    💡 Tab キーによる自動補完（シェル方式）:
    　Key入力中に Tab キーを押すと、共通する階層（例: @faci → @facility@）まで自動補完されます。候補が1件に絞られた状態で Tab を押すと、Key名全体が一発で確定します。
    💡 Keyの記法ルール（直接入力・階層指定時）:
    ・オブジェクト階層: @category@sub.key または @category@sub@key
    ・配列インデックス: @measurement@edges[0].element または @files[0].file[0].name
    ・独自パラメータ: JXS仕様外の独自項目も @local@custom_key のように自由に追加できます。
  • 項目説明カード (ヒント):

    　Keyを選択すると、日本語項目名、重要度バッジ（必須・推奨・任意）、型、許容値（Enum候補）、説明文、および入力例が表示されます。

  • 設定値（Value）の入力と適用・削除:

    　設定値の型に応じて、Enum（選択肢）は候補選択と自由入力ができるコンボボックス、日付・日時項目は過去の日付や測定時刻（秒単位）まで指定できる日時選択ダイアログ付きの入力欄、その他は通常入力欄に自動で切り替わります。

    　値を入力して 「適用 (Enter)」 ボタンを押すと右ペインのYAMLに即時反映されます。また 「ゴミ箱アイコン（削除）」 ボタンで項目をクリアできます。

入力サポート ＆ ToDo リスト (下部)

  • 未入力 ToDo リスト（必須 ＆ 推奨）:

    　「未入力の必須項目」および「未入力の推奨項目」が2列カードで常時一覧表示されます。

    　一覧内の項目をクリックすると、その項目が Key入力欄に直接セット され、順番に入力を進めることができます（全項目が埋まると完了表示に変化します）。

  • 設定済みの全項目一覧:

    　現在メタデータ内に設定されているすべての項目が一覧表示されます。修正したい項目をクリックすることで、いつでも即座に入力フォームへ呼び出して再編集できます。

3. YAMLプレビュー (右ペイン)

　画面右側で、生成される metadata.yml の構文ハイライト付きリアルタイムプレビューを確認できます（未保存の変更がある場合はファイル名に * アスタリスクが表示されます）。

  • 双方向ジャンプ編集（行クリック機能）:

    　プレビュー内の任意の行をクリックすると、その行に対応する項目（Key）が 左ペインの入力コンソールに即座に選択・展開 されます。編集したい場所をプレビューから直接狙って修正できます。

  • ホバーヒント切替 (ON / OFF):

    　ヘッダー右側の 「ヒント: ON/OFF」 ボタンで、YAMLプレビュー行にマウスを重ねた際に表示されるツールチップ（日本語項目名・型・説明）の表示／非表示を切り替えられます。

  • YAMLのコピー:

    　ヘッダー右側の 「コピー」 ボタンを押すと、現在表示されているYAML全文をワンクリックでクリップボードにコピーできます。

4. ファイル取り込み ＆ 衝突解決 (Conflict Resolution)

　現在編集中のデータを保持したまま、外部のYAML/JSONファイルを読み込んで マージ できます。共通のテンプレート（施設情報など）を取り込んで既存データに足し合わせる作業が安全に行えます。

  • ドラッグ＆ドロップ (D&D) による取り込み:

    画面上のどこでも .yml / .yaml / .json ファイルをドロップするだけで即座に取り込み・マージ処理が開始されます。

  • 衝突（コンフリクト）の検知と解決:

    取り込んだデータの中に、現在編集中の値と異なる項目がある場合、自動的に「衝突解決ダイアログ」が開きます。

    • 比較テーブル: 日本語項目名、重要度、項目（Key）、既存の設定値、読込ファイルの設定値が一覧表示されます。
    • 個別選択: 各行で 左:「維持 (既存優先)」 / 右:「上書き (ファイル優先)」 を個別に選択できます。
    • 一括操作: 上部の「すべて維持」「すべて上書き」ボタンで全項目を一括切り替えできます。

5. JXS XAFS メタデータ仕様の要点

　日本XAFS研究会（JXS）「XAFSメタデータ共通仕様（20230203リリース版）」に準拠するための重要ルールです。

📑 必須・推奨項目の確認方法:
　必須11項目および推奨12項目の詳細仕様（日本語項目名・型・Enum選択肢・説明文・入力例）は、上部の 「JXSスキーマ辞書」タブ を開き、重要度フィルタ（必須 (11) / 推奨 (12)）をクリックしてご確認ください。
　カードをクリックすると、左ペインの入力フォームに対象の項目（Key）が自動セットされます。

表記統一ルール（重要な書式制約）

  • 吸収端 (edge):

    ["K-edge", "L1-edge", "L2-edge", "L3-edge", "M-edge"]
    ※ すべて -edge を付ける表記で統一されています（例: K ではなく K-edge）。

  • 分光結晶面 (crystal_plane):

    ["111", "311", "220", "511"]
    ※ 括弧 (111) なしの数字のみで統一されています。

  • 面間隔単位 (crystal_d_unit):

    angstrom（オングストローム標準）

  • 二次利用ライセンス (license):

    MDR推奨値: CC BY-NC-SA 4.0
