# MDR XAFS DB 手動データ登録手順書（セルフ登録編 - v4）

本書は、物質・材料研究機構（NIMS）が運営する「[MDR XAFS DB](https://mdr.nims.go.jp/collections/qz20st57x)」へ、手作業あるいは自前の自動化スクリプトを用いてXAFSスペクトルデータ（9809フォーマット等）を登録するための実務マニュアルです。

---

## 1. MDRのデータ管理構造と情報の重複入力について

MDRは材料科学全般を対象とする汎用的なリポジトリであり、XAFS専用に特化したシステムではありません。そのため、データ登録時には**「Web登録フォームへの入力」**と**「提出用JSONファイル（JXS共通仕様）の添付」**の双方において、一部の共通する基本項目（タイトル、著者名、測定元素、ビームライン、ライセンス等）をそれぞれ入力（あるいはコピペ）する必要があります。

*   **二重のデータ管理の役割**: 
    1.  **MDR Webフォームの入力項目**: MDRプラットフォーム全体（汎用データベース）のインデックス、Web公開ページの生成、検索フィルター（ファセット）に使用されます。
    2.  **JXS仕様 of JSONファイル（添付ファイル）**: 日本XAFS研究会や国際ポータル（IXDB）など、XAFSに特化した専門データベース検索システムが、アンプのパラメータやスキャン条件といった高度な物理メタデータを自動抽出・解析するために使用されます。
*   **登録時における事実関係**:
    MDRの登録画面には、添付したJSONファイルから基本情報を自動で読み取ってフォームにマッピングする連携機能がありません。そのため、同一の基本情報を「Web画面」と「添付JSON」の両方にそれぞれ入力（またはコピー＆ペースト）し、整合性を保つ作業が必要となります。あらかじめこのデータフローの仕様を理解した上で作業を開始してください。

---

## 2. 事前準備：提出に必要なファイルの作成

MDRにXAFSデータを手動登録する際は、1スキャン（1ラン）のデータセットごとに、以下の必須ファイル（Required）および推奨ファイル（Recommended）を用意します。

| # | 必須度 | ファイル種類 | 命名規則例 | 内容と作成のポイント |
| :--- | :---: | :--- | :--- | :--- |
| **1** | **Required**<br>(必須) | **測定データ本体** | `sample.dat` | 9809フォーマット（可変長スペース区切り等）のテキストデータ。他ユーザーが解析で再利用するプライマリデータです。 |
| **2** | **Required**<br>(必須) | **JXSメタデータ** | `sample.json` | データの詳細属性（JXS共通仕様 `xafs-schema` 準拠）を記述したJSON。公開テンプレートをベースに編集するか、自作の自動化スクリプトで生成します。 |
| **3** | **Recommended**<br>(推奨) | **スペクトル画像** | `sample.png` | MDRの検索一覧や詳細ページで、ユーザーが一目でデータの品質を判断するためのプレビュー用スペクトルプロット画像（縦横比4:3推奨）。 |

💡 **スペクトル画像（Recommended）を同梱する場合のメタデータ記述**:
スペクトル画像（`.png`等）を添付して一緒に登録する場合は、JXSメタデータ（JSONファイル）内の `files` カテゴリへ対象のファイル情報を記載する必要があります。具体的には、`files` 配列に対象画像ファイル名（例: `sample.png`）の要素を追加し、その説明項目（`description`）に `"thumbnail"`、フォーマット（`format`）に `"image"` と指定して記述します。これにより、MDRシステムがプレビュー用の画像として正しく認識・処理できるようになります。

### 🛠️ 自作スクリプトでファイルを自動生成する場合の推奨ロジック
ローカル環境や、独自の開発ツールでこれらのファイルを出力させる場合、以下のアルゴリズムを実装することで登録作業を効率化できます。
1.  `.dat` ファイルのヘッダー部を自動スキャンし、ビームライン名、測定元素、測定ブロック数、露光時間、測定日時を自動でパースする。
2.  パースした値を、JXS共通仕様（`xafs-schema`）に沿ったJSON構造（`@data_info`, `@facility`, `@files`, `@measurement` 等）に配置し、`.json` ファイルとして書き出す。
3.  `matplotlib` や `plotly` を用いて、データのエネルギー（または角度）に対する吸収係数を自動プロット（透過法なら $\ln(I_0/I)$、蛍光法なら $I_f/I_0$）し、推奨ファイルであるサムネイル用の `.png` として自動保存する。この際、上記箇条書きのルールに則って、生成した `.png` ファイルのメタデータ情報（`description: "thumbnail"`, `format: "image"`）を自動でJSONの `files` 配列に挿入するようにします。

## 3. メタデータの整合性（重複入力チェックリスト）

Webフォームへの入力値と、添付するJSONファイルの内容は完全に一致させる必要があります。特にエラーやデータ不整合を防ぐために、以下の重要項目を統一させてください。

### A. 試料・物質に関する項目
*   **測定元素 (Element)** : 例 `Pt`, `Fe`, `Cu`（※元素記号の大文字小文字を正確に記述）
*   **吸収端 (Edge)** : 例 `K-edge`, `L3-edge`
*   **物質名 / 化学式 (Sample Name / Chemical Formula)** : 例 `Pt foil`, `Fe2O3`
*   **サンプルの状態 (Phase / State)** : 例 `solid`, `powder`, `liquid`, `film`

### B. 測定条件に関する項目
*   **測定施設名 (Facility Name)** : 例 `SPring-8`, `Photon Factory`, `AichiSR`
*   **ビームライン (Beamline)** : 例 `BL14B2`, `BL-9C`, `BL5S1`
*   **測定手法 (Mode / Method)** : 例 `transmission`（透過法）, `fluorescence`（蛍光法）
*   **測定日時 (Date)** : 測定が行われた日付（`YYYY-MM-DD` 形式）

### C. 登録者・ライセンスに関する項目
*   **データ登録者 (Creator / Depositor)** : 測定者の氏名（英語表記、例: `Taro KEK`）
*   **所属機関 (Affiliation / Organization)** : 例 `Ritsumeikan University`
*   **ORCID** : 16桁の研究者識別ID（例: `0000-0003-xxxx-xxxx`）。外部からの登録アカウントの紐づけに必須です。
*   **利用ライセンス (License)** : 原則として `CC BY-NC-SA 4.0`（クリエイティブ・コモンズ 表示-非営利-継承）等を指定します。

## 4. 詳細ステップバイステップ登録手順

### ステップA：MDRアカウントの認証
1.  **DICEアカウントの作成**
    *   [DICEウェブサイト](https://dice.nims.go.jp/services/MDR/) にアクセスし、サインアップおよびMDRの利用申請を行います。
2.  **ORCIDとの連携**
    *   MDRの管理画面にログイン後、プロフィールから「ORCIDに接続」を選択し、自身のアカウントを連携させます。
3.  **連絡用メールアドレスの認証**
    *   送信された認証メール内のURLをクリックし、デポジット（登録・申請）権限を有効化します。

### ステップB：提出用ファイルの格納
1.  手動での編集、あるいは自作のスクリプトを用いて、対象のデータに対応する「データ本体（`.dat`）」および「JXSメタデータ（`.json`）」（さらにスペクトル画像を用意する場合は「`.png`」）のファイルを同一フォルダ内に準備します。

### ステップC：MDRウェブ画面での手動入力とアップロード
1.  **登録フォームの起動**
    *   MDRシステムへログインし、「手動で登録（Add manually）」ボタンをクリックします。
2.  **Webフォームへの手動入力**
    *   事前に準備したJSONファイル（JXS仕様）に記述した内容（タイトル、測定者名、所属、ORCID、測定元素、吸収端、施設・BL名、ライセンス等）と**同一の内容**を、Webフォーム上の各入力項目欄に再度入力（またはコピー＆ペースト）します。
3.  **ファイルの添付**
    *   フォームの下部にあるアップロード（ドラッグ＆ドロップ）エリアに、用意した「`.dat`」「`.json`」（スペクトル画像も登録する場合は「`.png`」を加えた2枚または3枚のファイル）を同時に投入します。
    *   ※ドロップされたJSONファイルが、MDR XAFS DBの高度な物理検索用データとして登録されます。
4.  **保存**
    *   利用規約や権利関係の同意チェックを入れ、「保存」ボタンを押します。
5.  **審査依頼（Request a review）の送信**
    *   保存後の詳細画面において、**「MDR公開承認の依頼（Request a review）」**ボタンをクリックします。
    *   NIMSのMDR運用担当者による整合性チェックが実施され、問題がなければ数日以内に固有のDOIが付与され、正式に一般公開されます。
